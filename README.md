# Bible Verse Match

A small web app that matches a Bible verse to how you're feeling.

Pick a category — **Mood**, **Thoughts**, or **Situation** — then tap one option to get a matched verse (NIV) with a short reflection.

- 9 moods, 8 thoughts, 8 situations
- 2–3 verses per topic, with Another Verse, Copy Verse, and Surprise Me
- Tonight's Word, rotating daily
- Dark design, built for quiet, low-light reading

Open `index.html` in a browser, or serve it with any static host. No build step, no backend.
